# Redberry Assignment
A React-based web application built as part of the Redberry Bootcamp.

### Tech Stack
- React;
- JavaScript;
- Tailwind CSS;

### Project Structure
- src/
- components/ # Reusable UI components;
- pages/ # Page level components;
- hooks/ # Custom react hooks;
- services/ # API calls;
- utils/ # Helper Functions;

### Commit Convention
- feat: A new feature;
- fix: A bug fix;
- chore: Setup or configuration;
- refactor: Code improvements without changing behavior;
- style: UI or formatting changes;
- docs: Documentation updates;
